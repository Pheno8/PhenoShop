# 🛒 PhenoShop - L'Excellence E-commerce au Cameroun

PhenoShop est une plateforme de vente en ligne ultra-sophistiquée, conçue spécifiquement pour répondre aux besoins du marché camerounais (Yaoundé, Douala et au-delà).

## ✨ Pourquoi PhenoShop ?
*   **Vitesse Record** : Chargement optimisé pour les réseaux 3G/4G camerounais.
*   **Paiement Local** : Intégration prévue de **MTN Mobile Money** et **Orange Money**.
*   **Mobile-First** : Une expérience fluide sur tous les smartphones Android.
*   **Confiance** : Suivi de commande transparent pour une fidélisation maximale.

## 🛠 Stack Technique (Production-Ready)
*   **Framework** : Next.js 14 (App Router)
*   **Design** : Tailwind CSS & Shadcn/ui
*   **Base de données** : PostgreSQL avec Prisma
*   **Performance** : Cache Redis avec Upstash
